# Writing Style Guide

> `schema/*.json` defines structure (fields, types). This file defines
> *how the prose within those fields should read*. It's meant to be
> short and easy to tweak — edit it freely to match how you actually
> want to write.

- **Voice:** first person ("I explained...", "My manager confirmed...").
- **Tone:** concrete and factual over vague ("shipped X, manager
  confirmed Y" beats "had a good month").
- **Format:** bullet points, not paragraphs. One idea per bullet.
- **Evidence entries:** date-prefixed free text — `- [YYYY-MM-DD] text`.
- **Manager feedback:** paraphrase, don't transcribe as exact quotes.
- **Terminology:** follow `docs/terminology.md` (e.g. "1:1," not
  "one-on-one").

Adjust any of the above as your own preferences become clearer.
